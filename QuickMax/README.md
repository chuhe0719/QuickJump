# QuickMax

纯本地的安卓快递工具：首页一键直达各平台身份码 / 待取快递，第二页用拍照、截图或手动输入收录取件码。

这是**独立应用**（包名 `com.chuhe.quickmax`），与 QuickJump 不同签名、不同数据，可以同时安装。
当前版本 **10.19.7**（versionCode `1019007`）；版本号自 `10.19.0` 起算，versionCode 自 `1019000` 起递增。

> 零权限 · 零联网 · 零上传 · 无后台 · 无数据库

## 功能

### 首页

- **7 个入口卡片**：菜鸟身份码、淘宝身份码、拼多多身份码、淘宝待取快递、拼多多待取快递、抖音待取快递（兼容极速版）、京东待取快递
- **入口可自定义**：长按卡片改 deeplink，失效不用重新打包；每条入口有多级回退（换链接 → 拉起目标 App → 网页兜底）
- 底部「取件码」按钮或左滑进入第二页，右滑返回
- 左下角问号点头像看「关于」，长按可从相册换头像 / 换主页背景 / 编辑关于内容 / 恢复默认外观
- **桌面长按图标**：三个身份码 + 取件码快捷方式

### 取件码第二页

- **三种收录方式**：拍照识别（系统相机，零 CAMERA 权限）、从截图识别（相册选图或系统分享）、手动添加
- **本地离线中文 OCR**：一张图走 5 路识别（原图 / 放大 / 旋转 90° / 270° / 对比度增强）后合并去重，候选可勾选，重复自动跳过
- **格式宽松**：`8-2-1234`、`29 3 4304`、`A-5-3464` 都认；空格与 `-` 同为分隔符，全角字符与小写字母自动归一；支持一次输入多个码
- 「识别原文」可查看 OCR 实际读到的文字，便于核对漏识别
- **截图来源推测**：提示「这张图可能是 X 的待取快递」，默认**不自动标记**；只有主动勾选复选框，才给本次新增的码打上平台标签
- 点卡片**全屏大字显示**（递给店员看），长按切换「已取 / 未取」，另有删除、清空已取
- **三层标签**：平台类型 / 驿站类型 / 身份码类型（拼多多身份码、淘宝身份码、菜鸟身份码），每层可点 ＋ 自定义添加、长按删除，另有自由备注；选项存在本机

## 隐私

- 不申请任何权限；不读短信、通知、账号
- OCR 模型随 APK 打包（ML Kit bundled 中文模型，不需要 Google Play 服务），识别完全在设备本地，图片不上传
- ML Kit 传递引入的 `INTERNET` / `ACCESS_NETWORK_STATE` 已在清单里用 `tools:node="remove"` 移除
- 取件码、自定义链接、头像与背景图只存 App 私有目录，`allowBackup=false`
- 拍照走系统相机 + FileProvider，照片只写入 App 缓存目录

## 入口链接失效了怎么办

页面入口并非官方开放 API，菜鸟 / 淘宝 / 拼多多 / 抖音更新后可能失效：

1. 长按失效的按钮填入新链接，立即生效
2. 或改 `MainActivity.kt` 里的 `ENTRIES` 配置后重新构建

## 本地构建

JDK 17 + Android SDK 34：

```
./gradlew assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。
单元测试：`./gradlew :app:testDebugUnitTest`。
为控制体积只打包 `arm64-v8a` 并压缩原生库（APK 约 11MB）；32 位老设备 OCR 不可用，但手动添加仍可用。
